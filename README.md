# Сайт студии «Дарья Шугарья»

Технологии: Astro + TypeScript, статическая генерация, без базы данных и без отдельного платного хостинга.

## Быстрый старт

```
npm install
npm run dev
```
Сайт откроется на `http://localhost:4321`.

Собрать финальную версию:
```
npm run build
```
Результат появится в папке `dist/` — это то, что публикуется на хостинг.

## Где что менять (без поиска по компонентам)

Все переменные данные вынесены в папку `src/data/`:

| Файл | Что там |
|---|---|
| `src/data/site.ts` | Телефон, адрес, режим работы, ссылка YCLIENTS, соцсети, ID Яндекс.Метрики |
| `src/data/prices.ts` | Цены на все зоны, комплексы, предложение первого визита |
| `src/data/methods.ts` | Тексты и FAQ страниц лазера / шугаринга / воска |
| `src/data/masters.ts` | Мастера студии |
| `src/data/reviews.ts` | Отзывы клиентов |
| `src/data/partners.ts` | Партнёры и их персональные предложения |
| `src/data/blog.ts` | Статьи блога |

### Изменить цену
Открыть `src/data/prices.ts`, найти нужную зону, заменить `price: null` на число, например `price: 2500`. Цена обновится автоматически на странице услуги и на `/prices/`.

### Изменить телефон, ссылку YCLIENTS или режим работы
Открыть `src/data/site.ts` — там же UTM-метки для партнёров и статей формируются автоматически через функцию `withUtm`, отдельно её трогать не нужно.

### Добавить мастера
Добавить новый объект в массив в `src/data/masters.ts`. Карточка на `/masters/` появится автоматически.

### Добавить отзыв
Добавить объект в массив в `src/data/reviews.ts` (автор, источник, метод, текст, дата).

### Добавить статью в блог
Добавить объект в `src/data/blog.ts` (slug, заголовок, текст по абзацам, FAQ). Страница `/blog/ваш-slug/` создастся автоматически при следующей сборке.

### Добавить партнёрскую страницу
Добавить объект в `src/data/partners.ts`. Страница `/partners/slug-партнёра/` создастся автоматически и не будет индексироваться поисковиками (это сделано намеренно — такие страницы для конкретной аудитории, не для поиска).

### Добавить новую услугу второго этапа (например, «Лазерная эпиляция глубокого бикини»)
Такие страницы создаются как отдельные файлы в `src/pages/`, поскольку у каждой должна быть уникальная ценность и контент — по правилам ТЗ их не стоит штамповать автоматически. Скопируйте `src/pages/[slug]/index.astro` как основу.

### Заменить фотографии
Файлы кладутся в `public/images/...`, затем путь указывается в соответствующем месте (`src/data/masters.ts` для фото мастеров, компоненты страниц — для остальных). Сейчас на месте фото — плейсхолдеры с пометкой `[УКАЗАТЬ фотографию]`.

## Публикация: GitHub → Cloudflare Pages

1. Создать репозиторий на GitHub и запушить туда код проекта.
2. Зайти в Cloudflare Pages → «Создать проект» → «Подключить к Git» → выбрать репозиторий.
3. Настройки сборки:
   - Framework preset: **Astro**
   - Build command: `npm run build`
   - Output directory: `dist`
4. Нажать «Deploy». Cloudflare сам установит зависимости и соберёт сайт.

## Подключение домена daryasugarya.ru

1. В Cloudflare Pages открыть проект → вкладка «Custom domains» → добавить `daryasugarya.ru`.
2. Cloudflare покажет, какие DNS-записи нужны (обычно CNAME на `<проект>.pages.dev`, либо Cloudflare сделает это автоматически, если домен уже привязан к Cloudflare).
3. Если домен куплен на Reg.ru и не переведён на Cloudflare DNS — либо перенести DNS-управление в Cloudflare (в панели Reg.ru поменять NS-серверы на выданные Cloudflare), либо добавить CNAME-запись вручную в панели Reg.ru на `<проект>.pages.dev`.
4. SSL-сертификат Cloudflare выпускает автоматически.

## Подключение Яндекс.Метрики

1. Создать счётчик в Яндекс.Метрике, скопировать его номер.
2. В `src/data/site.ts` заменить `yandexMetrikaId: '[УКАЗАТЬ ПОСЛЕ СОЗДАНИЯ]'` на реальный номер.
3. В `src/layouts/Layout.astro` раскомментировать блок с кодом Метрики (сейчас закомментирован, чтобы не мешать разработке) и вставить туда стандартный код счётчика с сайта Метрики.
4. Цели (`click_booking_hero`, `outbound_yclients` и другие) уже расставлены как атрибуты `data-goal` на кнопках — их нужно будет связать с целями в интерфейсе Метрики (по клику на элементы с этим атрибутом) или добавить небольшой JS-обработчик, который отправляет `ym(ID, 'reachGoal', dataset.goal)` при клике.

## Добавление сайта в Яндекс.Вебмастер

После публикации: зайти в Яндекс.Вебмастер → добавить сайт `daryasugarya.ru` → подтвердить права (через метатег или файл) → отправить `sitemap-index.xml` (создаётся автоматически при сборке).

- Точный адрес студии, этаж/вход/домофон, время пешком от метро
- Телефон, ссылки на WhatsApp/Telegram, соцсети

- Тексты политики конфиденциальности и согласий (рекомендуем — с юристом)

- Кабинет, зона ожидания, вход, детали интерьера

## Технические примечания

- Архитектура позволяет добавлять новых мастеров, партнёров, статьи и отзывы без переделки шаблонов — только через файлы в `src/data/`.
- Страницы лазера/шугаринга/воска используют один общий шаблон (`src/pages/[slug]/index.astro`) с данными из `src/data/methods.ts` — так проще поддерживать единообразие и добавлять новые направления.
- Партнёрские страницы помечены `noindex`, чтобы не создавать дубли в поиске.
- Микроразметка Schema.org подключена: BeautySalon, Service, Person, BreadcrumbList, FAQPage, Article. AggregateRating сознательно не добавлен — только после появления реальных отзывов.
- Sitemap.xml генерируется автоматически при сборке через `@astrojs/sitemap`.
